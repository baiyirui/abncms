## 🌱 Почему мы создали ABNCMS

Мы хотим создать систему управления контентом, которая **действительно принадлежит каждому**.

Раньше создание сайта означало целый набор проблем: купить сервер, настроить базу данных, платить каждый месяц, следить за обновлениями безопасности и пересобирать проект при каждом изменении текста. Для отдельных блогеров, небольших команд и сайтов с ресурсами, где контент обновляется нечасто, это означало долгие годы платить за тяжёлую инфраструктуру, которая им почти не нужна.

При этом бесплатный план Cloudflare уже достаточно мощен, чтобы постоянно работать с настоящими сайтами: глобальная edge-сеть, база данных D1, KV, бесплатный HTTPS и защита от DDoS. Но нам не хватало CMS с открытым кодом, **спроектированной вокруг бесплатной квоты и при этом сохраняющей удобный визуальный редактор с админкой**: статические сайты быстры, но требуют пересборки при каждом изменении; динамические — гибки, но требуют денег на сервер.

**ABNCMS создана, чтобы заполнить этот пробел:**

> Любой человек с бесплатным аккаунтом Cloudflare может получить сайт с глобальным ускорением, без обслуживания, с админкой и контентом, который можно обновлять в любой момент — абсолютно бесплатно и с полностью открытым кодом.

Именно поэтому мы перевели документацию на несколько языков: дух открытого исходного кода в том, чтобы **люди в любой точке мира могли одинаково пользоваться проектом, понимать его и улучшать его**. Язык не должен быть барьером.

## ✨ Ключевые преимущества

### 1. Реально нулевая стоимость
Всё работает в рамках бесплатного плана Cloudflare: **без сервера и без привязки карты**. D1, KV, Worker и AI укладываются в бесплатную квоту; единственная production-зависимость — `hono`.

### 2. Глобальное ускорение «из коробки»
Страницы кэшируются на **300+ edge-узлах** Cloudflare по всему миру, поэтому каждый посетитель обращается к ближайшему узлу и получает одинаково плавный опыт в любом регионе. Бесплатный HTTPS-сертификат и защита от DDoS включены по умолчанию.

### 3. Есть админка, обновляйте в любое время
В отличие от чисто статических сайтов, пересобирать проект не нужно. Пишите статьи, загружайте изображения и меняйте настройки в **визуальной админке** — фронтенд обновляется мгновенно. После публикации вы по-прежнему сохраняете полный контроль.

### 4. Мгновенный edge-кэш
При попадании в кэш страницы: **0 запросов к базе данных, 0 чтений/записей KV**, а полный HTML отдаётся напрямую. При публикации или правке статьи достаточно увеличить генерацию кэша `cache_gen` на +1 — старый кэш мгновенно становится недействительным, и весь сайт обновляется за секунды без очистки каждой страницы по отдельности.

### 5. Лёгкость и контролируемое потребление
В админке можно по отдельности включать и выключать кэш страниц, популярные статьи, похожие материалы, семантический поиск, AI-краткие описания, комментарии и статистику посещений. Небольшой сайт может в один клик перейти на режим «только HTML-кэш + несколько чтений», чтобы тратить бесплатную квоту там, где это действительно важно.

### 6. SEO-дружелюбие и безопасность
Псевдостатические адреса `/p/{slug}.html` + 301-редиректы старых ссылок, RSS, Sitemap и структурированные данные JSON-LD; пароли PBKDF2, сессии в KV, проверка одного источника, ограничение числа неудачных попыток, токены с шифрованием AES-GCM и полностью параметризованный SQL.

### 7. Данные всегда можно забрать с собой
Полный экспорт и импорт резервных копий — ваши данные принадлежат вам. Открытый код под лицензией MIT: делайте форк, дорабатывайте или разворачивайте приватно без ограничений.

## 💰 Бесплатная квота, потраченная с умом

| Ресурс | Бесплатная квота | Оптимизация ABNCMS |
|---|---|---|
| Workers | 100 000 запросов / день | Прямой ответ из edge-кэша, лёгкий рендеринг |
| База данных D1 | 5 млн прочитанных строк / 100 000 записанных | 0 запросов при попадании в кэш, не более 5 иначе; списки всегда идут по индексу |
| KV | 100 000 чтений / 1 000 записей | HTML страниц лежит в Cache API, **не расходует квоту записи KV** |
| Workers AI | 10 000 нейронов / день | Краткие описания, теги и семантический поиск выключены по умолчанию, включаются по необходимости |

> При анонимном посещении с попаданием в кэш: **0 запросов к D1, 0 чтений/записей KV** — скорость статического сайта с возможностью обновления «в любой момент», как у динамического.

## 🚀 Быстрый старт

От клонирования до публикации — всего несколько команд. Достаточно бесплатного аккаунта Cloudflare.

```bash
# 1. Клонируйте проект и перейдите в него
git clone https://github.com/baiyirui/abncms.git && cd abncms

# 2. Установите зависимости
npm install

# 3. Подготовьте конфигурацию (укажите account_id / D1 / KV ID)
cp wrangler.example.jsonc wrangler.jsonc
cp .dev.vars.example .dev.vars

# 4. Инициализируйте локальную базу и запустите проект
npm run db:local
npx wrangler d1 execute cf-press-db --local --file=./seed.sql
npm run dev          # → http://127.0.0.1:8787

# 5. Разверните на глобальной edge-сети Cloudflare
npx wrangler login
python scripts/setup_remote.py    # Автоматически создаёт D1 / KV / Vectorize и подставляет ID
npm run db:remote
npx wrangler secret put ADMIN_PASSWORD
npm run deploy
```

После развёртывания админка доступна по адресу `/admin/login`. Войдите впервые с `ADMIN_PASSWORD` из `.dev.vars` и сразу же смените пароль. Подробные шаги — в [полном руководстве разработчика](https://cms.abn.cn/docs.html).

## 🧩 Обзор возможностей

- **Фронтенд**: баннер на главной, лента статей (`/p/{slug}.html`), отдельные страницы, категории / теги / архив, полнотекстовый поиск, рендеринг Markdown, предыдущая и следующая статья, похожие статьи, комментарии, RSS / Sitemap / JSON-LD, адаптивная боковая панель
- **Админка**: защита входа (PBKDF2 + сессия в KV + ограничение попыток + Turnstile), управление статьями и страницами, Markdown-редактор с двумя панелями, визуальная настройка токена для хранения изображений, загрузка логотипа сайта, код сторонней аналитики, меню навигации, ссылки на дружественные сайты, медиатека, модерация комментариев, полный экспорт/импорт резервной копии, настройки сайта
- **Cron**: ежедневная очистка в 03:00 UTC устаревших данных о посещениях и спам-комментариев

Кроме базового рендеринга, почти все возможности фронтенда можно включать и выключать в админке.

│   ├── index.ts           # Все маршруты + Cron + стратегия кэширования
