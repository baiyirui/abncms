- You may freely use, modify and redistribute the code under MIT, including

- If you distribute a **modified** version, do not call it "ABNcms" or use the
  ABNcms logo in a way that suggests it is the official distribution.
- Naming a fork for identification purposes (for example "ABNcms fork by X")

- Themes, extensions and marketplace listings may say "for ABNcms" to describe
  compatibility; they may not imply endorsement.

## Why

An open-source CMS needs a stable name so users can tell the official release
from a repackaged build. This file protects that name without restricting what
you can do with the code.

Questions about branding or a request to use the marks: open an issue in the
official repository.
